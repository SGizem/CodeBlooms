# CodeBlooms - REST API Görevleri (Sedef Gizem Orulluoğlu)

** Yayınlanan REST API Domain Adresi:** https://codeblooms.onrender.com
** Test Kanıt Videosu (YouTube):** [[Video Linki Buraya Gelecek](https://youtu.be/DnQ3Rr3B6QI)]

## Gerçekleştirilen API Metotları ve Yollar

1. **Kullanıcı Kaydı:** POST /api/users/register
2. **Kullanıcı Girişi (Ekstra):** POST /api/users/login
3. **Ürün Ekleme:** POST /api/products
4. **Ürün Silme:** DELETE /api/products/{productId}
5. **Ürünleri Listeleme:** GET /api/products
6. **Sipariş Güncelleme:** PUT /api/orders/{orderId}
7. **Sipariş Listeleme:** GET /api/orders/{userId}
8. **Yorum Ekleme:** POST /api/comments/products/{productId}/comments
9. **Yorum Silme:** DELETE /api/comments/{commentId}
