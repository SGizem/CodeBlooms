# REST API Görev Dağılımı

**REST API Adresi:** [https://codeblooms.onrender.com](https://codeblooms.onrender.com)

Bu dokümanda, CodeBlooms projesi kapsamında ekibindeki her üyenin geliştirmekten sorumlu olduğu REST API metotları listelenmektedir. Her üye kendi metotlarının backend (Node.js/Express) implementasyonunu, veritabanı (MongoDB) bağlantılarını ve Postman testlerini gerçekleştirmiştir.
